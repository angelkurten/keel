## 5. Degenerate cases

A bootstrap interval collapses to a point when every resample is the same: an accuracy of 1.00 (or 0.00) on every question, or two systems right and wrong on exactly the same questions. "0 [0, 0], p = 1.0" then says nothing about uncertainty and should not be printed as a test result. Report instead (a) the count: "identical on all 315 questions (0 discordant)"; (b) each accuracy with an exact (Clopper-Pearson) interval, e.g. 72/72 = 1.00 [0.95, 1.00], 0/72 = 0.00 [0.00, 0.05]; (c) if a bound on the difference is wanted, the exact upper bound on the discordance rate: with 0 discordant of n, at most 1 - 0.025^(1/n) (n = 315: 1.2 points; n = 72: 5.0 points), so the difference lies within +/- that; and (d) leave such cells out of the Holm family or keep them at p = 1, which changes no other adjusted p. Where a bootstrap p is 0 it means p < 1/B = 0.0001, not 0; it enters Holm as 1/B. Sonnet's one-issue Keel vs API and vs RAG are this case: the three systems are right on the same 313 and wrong on the same 2 questions.
