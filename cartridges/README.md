# Your cartridges

Put your own cartridges here, one folder each (`cartridge.yaml` and `handlers.py`): `keel init cartridges/<name>` scaffolds one.

The four in `examples/` (fleet, crm, finance, clinics) show the shape, each with its events and a test; copy one as a starting point. [Your first cartridge](../docs/first-cartridge.md) walks through building one in 20 minutes.
